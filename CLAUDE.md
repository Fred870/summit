# Summit – notes for Claude

- iOS 18+, SwiftUI app with a SpriteKit scene. Swift 5 language mode. Project generated by XcodeGen from `project.yml`; never commit `*.xcodeproj`.
- Claude can't build here (no Xcode). Keep pure game logic in `App/Game` free of Apple UI frameworks so it can be type-checked and tested with a Linux Swift toolchain (`swift test` in a temporary package that copies `App/Game` + `Tests`).
- Design tokens live in `App/Design/Theme.swift` and must match `design-system.md` (Day/Night follow the sky, summit gold `sun` is the only accent, climber colours only on climbers).
- Scene rules (`App/Scene`): everything on the slope is placed by trail distance through `trailPoint(_:)`, anchored at its feet, as a child of `world`. Background/foreground layers are camera children that offset by camera × speed. Never animate slope objects independently of the world.
- Health rules: Flights Climbed only, exclude user-entered samples, count by sample time.
- Item values live in `ItemRules`; the server is the source of truth for progress.
- Keep anything from Aniva out of this project.
